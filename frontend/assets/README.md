# 品牌素材

把官方素材放進這個資料夾，前端會自動改用，**不需要改任何程式碼**。
找不到檔案時會退回 `index.html` 內建的替代圖形。

| 檔名 | 用途 | 說明 |
|---|---|---|
| `logo.svg` 或 `logo.png` | 首頁品牌標誌 | 建議 SVG。橫式標誌會以高度 34px 顯示、寬度自動 |
| `mascot.gif`、`mascot.svg` 或 `mascot.png` | 載入畫面的吉祥物金寶 | 依此順序偵測。GIF 可直接帶動畫 |

## 為什麼預設是替代圖形

官方 logo 與金寶的美術素材不在本 repo 中，也無法從官網自動取得（官網為前端渲染的 SPA），
因此 `index.html` 內建了一組配合品牌橘（`#f37021`）的替代圖形，讓系統在沒有素材時仍可完整展示。

正式對外展示前，請把官方檔案放進此資料夾以取得正確的品牌識別。

## 驗證

放入檔案後重新載入頁面即可。若沒有生效，開瀏覽器 DevTools 的 Network 分頁，
確認 `assets/logo.svg` 之類的請求回傳 200 而非 404。
