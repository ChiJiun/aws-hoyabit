# 異常訊號分析 — 詳細規劃

TA:主動交易者。價值主張:完整可信的資訊 + 有參考價值的異常訊號。
本文件定義訊號分類、計算方式、判定門檻、責任模組與報告呈現,是各 spec 相關修訂的依據。

## 一、設計原則

1. **偵測用程式,解讀用模型**:所有異常判定由決定性計算產生(數值 + 歷史百分位 + 門檻),LLM 只負責解讀「為什麼值得注意」與跨源整合,不負責算數。
2. **低耦合**:單源異常由各工具自己標記(自帶 anomaly_flags),跨源背離由推理層比對——工具之間仍然互不相識。
3. **每個訊號都是證據**:異常訊號必附 evidence_id、計算參數、百分位,可回溯可查證。
4. **寧缺勿濫**:無異常就明說「本期各項指標處於常態區間」,這本身就是有價值的資訊,也展現不硬給結論的紀律。

## 二、訊號分類與判定規則

### A. 單源異常(各工具自行偵測,隨 summary 回報)

| # | 訊號 | 責任工具 | 計算 | 異常門檻(預設) |
|---|---|---|---|---|
| A1 | 量能異常 | quant | 成交量 Z-score(20d)+ 百分位(365d) | 百分位 ≥ 95 或 ≤ 5 |
| A2 | 波動壓縮/爆發 | quant | 布林帶寬百分位(365d) | ≤ 10(壓縮,常為變盤前兆)或 ≥ 90(爆發) |
| A3 | 真實波幅極端 | quant | ATR% 百分位(365d) | ≥ 90 |
| A4 | 趨勢強度極端 | quant | ADX 百分位 | ≥ 85(強趨勢)或 ≤ 15(無方向) |
| A5 | 單日/週漲跌幅極端 | quant | 報酬率相對已實現波動率的倍數 | |z| ≥ 2 |
| A6 | 情緒極端 | sentiment | Fear & Greed 值 + 7 日變化 | ≤ 20 / ≥ 80,或 7 日變化 ≥ 30 點 |
| A7 | 新聞密度突增 | news | 近 48h 新聞數 vs 前 14 日日均 | ≥ 3 倍 |
| A8 | 重大官方事件 | news | 官方公告/GitHub release 關鍵字(upgrade、halt、hack、listing、regulation) | 命中即標 |
| A9 | 鏈上活躍度偏離 | onchain | 活躍地址/交易數 vs 30 日均 | 偏離 ≥ ±30% |
| A10 | 總經環境轉向 | macro | DXY / 10Y 殖利率 20 日變化方向與幅度 | 變化幅度近一年百分位 ≥ 85 |

門檻集中在 config.py(ANOMALY_THRESHOLDS dict),賽前可依演練結果調整,不寫死在工具內。

### B. 跨源背離(推理層比對,最有價值的產出)

| # | 背離型態 | 比對來源 | 交易者為何在乎 |
|---|---|---|---|
| B1 | 價格 ↓ 而鏈上活躍度 ↑(或反向) | price × onchain | 價格走勢與基本面使用量脫鉤,可能是情緒性賣壓或吸籌 |
| B2 | 價格 ↑ 而量能萎縮 | price × quant | 上漲缺乏參與度,續航力存疑 |
| B3 | 情緒極端但價格未反應 | sentiment × price | 情緒指標常為反向訊號,錯位時值得注意 |
| B4 | 新聞面與價格方向相反 | news × price | 市場「不理會」利多/利空,本身是強訊號 |
| B5 | 與 BTC 相關性斷裂 | quant(correlation)| 長期相關的幣種脫鉤 = 幣種自身事件驅動,需找原因 |
| B6 | 總經逆風但幣價逆勢走強(或反向) | macro × price | 相對強弱透露資金偏好 |

實作:SYSTEM_PROMPT 內建「背離檢查清單」(B1–B6),要求模型逐項核對已取得的證據並明確回答「有/無/資料不足」;每個判定必須引用兩側的 evidence_id。

### C. 訊號分級(報告呈現用)

- 🔴 **顯著**:單源百分位 ≥ 95/≤ 5,或任一跨源背離成立且兩側證據充分
- 🟡 **關注**:單源達門檻但接近邊界,或背離成立但一側證據薄弱
- ⚪ **常態**:未達門檻——明確寫出「已檢查、無異常」的項目清單

每個訊號輸出固定結構:訊號名稱、方向、數值與百分位、historical context(上次出現類似讀值是何時)、為什麼值得注意(一句話)、evidence_id、信心與限制。

## 三、模組責任分配(對應各 spec 的修訂)

| 模組 | 新增責任 | 規模 |
|---|---|---|
| core-infrastructure | config 增加 ANOMALY_THRESHOLDS | 小 |
| market-data-tools | quant 增加 detect_price_anomalies(A1–A5),回傳含 anomaly_flags | 中 |
| intel-data-tools | sentiment/news/onchain/macro 各自附 anomaly_flags(A6–A10) | 小×4 |
| agent-orchestrator | SYSTEM_PROMPT 加入背離檢查清單 B1–B6 + 分級規則 | 中 |
| report-delivery | 報告模板新增「⚡ 異常訊號」章節(位於市場判斷之後);無異常時渲染常態聲明 | 中 |
| frontend-ui | 異常訊號卡片化呈現(紅/黃/白),Demo 視覺重點 | 中 |

契約影響:C1 增加選用欄位 `anomaly_flags: list[dict]`(向後相容,不影響既有欄位)。

## 四、報告呈現(範例骨架)

```markdown
## 市場判斷
…(結論 + 信心等級)

## ⚡ 異常訊號
### 🔴 量價背離:價格上漲 8.2% 但成交量 Z-score -1.1(近一年第 18 百分位)
- 數據:… (evidence #4, #9)
- 為什麼值得注意:上漲期間參與度偏低,歷史上類似組合(2025-11、2026-02)後續兩週…
- 限制:僅兩次歷史樣本,不構成統計顯著性

### 🟡 情緒與價格錯位:F&G 78(貪婪)而週報酬僅 +1.2%
…

### ⚪ 已檢查、無異常:波動帶寬(第 54 百分位)、鏈上活躍度(30 日均 ±6%)、與 BTC 相關性(0.81,常態區間)

## 關鍵依據
…
```

## 五、實作順序(疊加在現有 wave 上,不影響主線)

1. Wave 1 同步:quant 的 A1–A5(和 percentile_rank 一起寫,幾乎免費);四個 intel 工具各加 2–5 行 flag 邏輯
2. Wave 2:SYSTEM_PROMPT 背離清單;report 模板異常章節
3. Wave 3(演練期):用五幣種歷史資料回放,校準門檻(太鬆=雜訊,太緊=每次都「無異常」;目標:每次執行 1–3 個 🔴🟡 + 明確的 ⚪ 清單)
4. 加分項(有餘裕才做):異常訊號的歷史對照(「上次出現此組合是 X,之後 …」)——這是「洞察的分析角度」最便宜的來源

## 六、風險與紅線自檢

- 異常訊號 ≠ 交易訊號:呈現用「值得注意/歷史上曾…」,禁用「建議買入/突破進場」句式(validate_before_export 禁語清單涵蓋)
- 門檻是拍腦袋的起點,務必經 Wave 3 回放校準,並在報告限制中揭露門檻設定
- 跨源背離依賴兩側資料都取得;單側失敗時降級為「無法檢查 BX(缺 Y 資料)」寫入信心說明
